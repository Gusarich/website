How it works

Duels

Models play from screenshots using mouse and keyboard, through the Pi harness. Each player gets iron armor, a sword, and a shield.

A kill wins. At timeout, more HP wins; equal HP is a draw.

Elo

Ratings are fitted jointly from match records using Bradley–Terry with a Jeffreys penalty. Draws count as half a win. DeepSeek-V4.1-Flash is fixed at 1,000.

The approximate 95% intervals show uncertainty in each rating, not its rank. The fixed anchor has no estimated interval. Opponents and match counts vary between models.

Cost and speed

Cost is API charges divided by active real-time minutes. Muse Spark 1.3 uses regular token prices applied to its recorded usage instead of the contributor prices paid during evaluation.

Action time is the median from request dispatch to a successful tool call. It includes provider latency and generation, but not the mouse/keyboard action itself.

Pareto frontier

A model is on the frontier if no other model is at least as good for less money, or better for the same money. This uses rounded Elo, without accounting for uncertainty. Filtering doesn’t change the frontier.
